# Tecnocel — Laboratorio Celular
Proyecto Final de Estadías Profesionales

## Estructura
- `frontend/` → Landing page (HTML + CSS + JS)
- `backend/`  → API REST + Bot WhatsApp (Node.js)
- `analytics/` → Scripts de análisis (Python)

## Inicio rápido
```bash
# Backend
cd backend && npm install && npm run dev

# Bot WhatsApp
node src/bot/bot.js

# Analytics
cd analytics && pip install -r requirements.txt && python analizar.py
```
